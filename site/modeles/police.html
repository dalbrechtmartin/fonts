Fonctions OpenType

Qu’est-ce qu’une fonction OpenType ?

Des variantes rangées dans la police, que tu actives au besoin. Le texte ne change pas, seulement le dessin des lettres.

Exemple : le zéro barré évite de confondre 0 et O dans un code.

Où l’activer : dans InDesign, Affinity ou Word (menu OpenType), ou en CSS : font-feature-settings: "zero" 1;

Coche une fonction : l’essai et le CSS à copier se mettent à jour. Dans les aperçus, les signes qui changent sont sur fond foncé.
