    Mes polices

    Les polices d'écriture que je dessine. Tu peux les essayer ici, les télécharger et les utiliser librement : elles sont sous licence OFL.

    Chargement…

    1. Télécharger le zip de la police, par exemple griffonne-1.0.0.zip.
    2. Sur un ordinateur : installer le fichier .otf ou .ttf (double-clic, puis Installer).
    3. Sur un site : servir le fichier .woff2 avec le code CSS donné sous chaque police.
    4. Licence OFL : utilisation libre, même commerciale ; la police ne se vend pas seule et garde ses crédits.
