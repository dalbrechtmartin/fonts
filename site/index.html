    Utiliser une police

    1. Télécharger le zip de la version voulue.
    2. Sur un ordinateur : installer les fichiers .ttf.
    3. Sur un site : servir les fichiers .woff2 avec le code CSS donné sous chaque police.
    4. Licence OFL : utilisation libre, même commerciale ; la police ne se vend pas seule et garde ses crédits.
